Overview
Tic-Tac-Toe Interactive is a Java Swing-based desktop game that allows two players to play the classic Tic-Tac-Toe game with an attractive graphical user interface.
The application includes score tracking, restart functionality, winner detection, and tie-game handling.

Features
2 Player Game
Score Tracking
Winner Detection
Tie Detection
Restart Button
Simple GUI using Java Swing

Technologies Used
Java
Swing
AWT

How to Run

Save the file as:
TicTacToeInteractive.java

Compile the program:
javac TicTacToeInteractive.java

Run the program:
java TicTacToeInteractive

Game Rules
Player X starts first.
Players play one turn at a time.
First player to match 3 symbols in a row, column, or diagonal wins.
If all boxes are filled and no one wins, the game is a tie.
